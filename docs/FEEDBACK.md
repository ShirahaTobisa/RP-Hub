# 使用统计与问题报告

导航中的「运行日志」会保存最近的关键操作和错误类型。遇到问题后选择问题类别，可填一句说明，展开报告查看后手动发送；成功后可复制报告编号，也可下载 JSON 文件自行发送。日志不会自动上传。

日志最多保留 300 条、64 KiB，报告最多 128 KiB。不记录聊天或卡片正文、请求正文、请求地址、密钥、同步密码及错误消息原文。角色只用本次页面内的 C1、C2 代号表示。本机记录与统计开关不参加云同步。

基础使用统计默认开启，首次进入会说明，可在「运行日志」关闭。Worker 用 Cloudflare 账户 ID 生成 SHA-256 代号，只发送代号、测试版与官方版本。同一账户的多个站点算一个；多人共用账户也算一个，所以数字代表活跃账户，不是精确人数。每个浏览器每天最多尝试一次，站点当天成功发送后不再发送。

账户信息优先取 `CF_ACCOUNT_ID`，没有时复用现有 `CF_API_TOKEN` 的账户查询。不使用新版、关闭统计、没有账户信息或请求没送达的站点不会计入。配置了同步密码的站点仍要求浏览器已保存密码。

分发站 `/admin#feedback` 供管理员查看活跃账户及版本分布，查看、下载、按编号查找和删除报告；其他人不能读取。统计保留账户最后一次活跃记录，报告保留至管理员删除。报告编号可发给维护者协助排查。

## 开发检查

`npm test` 检查模块生成结果、同步请求、异步任务和原有核心行为。浏览器检查新增事务回滚及全部插件联合启动场景。

联测反馈接口与管理页时，先准备分发站源码，再设置 `RPH_MIRROR_DIR` 为其绝对路径，执行 `npm run test:feedback`。使用模拟账户、内存 R2 和无界面浏览器，不连接线上反馈接口。运行 `node tests/self-modules/current-version.mjs` 可检查现行版往返；需保留 Git 标签 `2026.11.10.2` 及准备好的最新上游底稿。截图写入忽略提交的 `evidence/self-modules/`。
