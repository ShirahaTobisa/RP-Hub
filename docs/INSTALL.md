# 安装与更新

RP-Hub 测试版部署在 Cloudflare Pages 上，云同步、图片和在线更新的数据放在 Cloudflare R2。免费计划就够用，全程在 Cloudflare 网页后台操作，不用安装任何软件。

**第一次需要手动部署；之后设置好一键更新，就可以在网页里直接更新。**

> Cloudflare 后台的按钮文字偶尔会调整，下面写的是 2026 年 10 月的叫法，找不到时按意思找相近的入口。

## 准备

- 一个 Cloudflare 账号，免费计划即可。
- 开通 R2：后台左侧「R2 对象存储」。第一次开通时 Cloudflare 可能要求绑定付款方式，免费额度内不会扣费。

## 一、第一次部署

### 1. 下载部署包

打开分发站 <https://update.rph.mornye.uk/>，在「测试版」里点「下载部署包」，得到 `RP-Hub-<版本>.zip`。**不用解压**，下面直接上传 ZIP。

### 2. 创建 R2 存储桶

后台 →「R2 对象存储」→「创建存储桶」，名字随意（例如 `rph-data`），其余保持默认，创建。

### 3. 创建 Pages 项目并上传

后台 →「Workers 和 Pages」→「创建」→ 选「Pages」→「上传资产」（直接上传）：

1. 填项目名称，它会成为网址 `<项目名>.pages.dev`。
2. 上传第 1 步的 ZIP，点「部署站点」。

### 4. 绑定存储桶、设置同步密码

进入刚建的 Pages 项目 →「设置」：

| 位置 | 类型 | 名称 | 值 |
| --- | --- | --- | --- |
| 绑定 | R2 存储桶 | `RP_SYNC_R2` | 第 2 步的存储桶 |
| 变量和机密 | 密钥 | `RP_SYNC_PASSWORD` | 你自己的同步密码 |

- 名称要一字不差，区分大小写。
- 设置在「生产」环境。
- **同步密码必须设置。** 不设置时任何人都能读写你的云同步数据，一键更新也会被禁用。

### 5. 重新部署，让设置生效

绑定和变量只对之后的部署生效：项目 →「部署」→ 最新一次部署右侧的「…」→「重试部署」。也可以再上传一次同一个 ZIP。

### 6. 检查

打开 `https://<项目名>.pages.dev`，导航菜单 →「同步」→ 输入同步密码，能打开云同步面板就成功了。

- 已经有云端数据（比如从旧站点迁过来、同一个存储桶）：点「拉取」。
- 全新的站点：用一段时间后点「上传」备份。

### 7. 更新到最新的上游页面（建议）

部署包里自带一份上游页面作为底稿。云同步面板 →「程序更新」→「检测版本」→ 选最新版 →「更新版本」，就会换成分发站收录的最新上游版本。

## 二、打开一键更新（设置一次）

### 1. 创建 Cloudflare 令牌

打开 <https://dash.cloudflare.com/profile/api-tokens> →「创建令牌」→ 最下面「创建自定义令牌」：

- **权限**：帐户 → Cloudflare Pages → 编辑
- **帐户资源**：包括 → 你的站点所在的帐户（只选这一个）

创建后复制令牌。令牌只在这一页显示一次，**不要发给别人，也不要贴到聊天里**。

### 2. 把令牌和帐户 ID 填进 Pages 项目

项目 →「设置」→「变量和机密」：

| 类型 | 名称 | 值 |
| --- | --- | --- |
| 密钥 | `CF_API_TOKEN` | 上一步的令牌 |
| 变量 | `CF_ACCOUNT_ID` | 帐户 ID：后台网址 `dash.cloudflare.com/` 后面那串 32 位字符 |

不想填 `CF_ACCOUNT_ID` 的话，也可以在第 1 步给令牌多加一个「帐户 → 帐户设置 → 读取」权限，站点会自己查。

### 3. 重新部署一次

同「一、5」。

### 4. 使用

云同步面板 →「测试版更新」→「检测版本」→ 选择版本 →「一键更新」。站点会把这个版本部署到自己身上，约半分钟后页面自动刷新。出问题点「回退上一次部署」。

## 三、以后怎么更新

| 要更新的 | 在哪里 | 说明 |
| --- | --- | --- |
| 测试版本体 | 云同步 →「测试版更新」 | 设置了令牌：一键更新。没设置：「下载部署包」，到 Pages 项目「部署」→「创建部署」上传 ZIP，绑定和变量会保留。 |
| 上游页面 | 云同步 →「程序更新」 | 上游发新版后，分发站收录即可更新，可回滚上一版。 |
| 插件 | 「模块管理」→「工坊」 | 一键安装和更新；更新会保留插件的设置和数据。 |

三者互不影响：更新测试版不会改动上游页面，更新上游页面也不会改动测试版。

## 四、可选设置

都在 Pages 项目「设置」→「变量和机密」，改完要重新部署。

| 名称 | 类型 | 作用 |
| --- | --- | --- |
| `IMAGE_GEN_TOKEN` | 密钥 | 服务器端的生图密钥。浏览器里没填生图密钥时使用它。 |
| `IMAGE_PROVIDER_STD_URL` | 变量 | 改用其他兼容的生图服务地址。 |
| `APP_UPDATE_MIRROR_BASE` | 变量 | 分发站地址，默认 `https://update.rph.mornye.uk`。填 `off` 关闭；关闭后测试版更新和工坊不可用，上游更新改为直接从 GitHub 获取。 |

RPH「设置」→「生图设置」里多了生图接口、分辨率（标准 / 2K / 4K）、采样器、噪声调度、生成步数、引导值和负面提示词。2K、4K 按官方价格计费（竖图 V4.5 28 步分别约 34、51 点/张），步数下面会显示当前设置每张图的点数。这些设置存在站点的 R2 里，所有设备共用，只影响之后的新图。想要超过 28 步，在「模块管理 → 工坊」安装「Nai2API 网页任务生图」插件，再在「生图接口」里选它；超过 28 步按 NovelAI 官方价格计费（竖图 V4.5 35 步约 24 点/张，28 步只要 1 点）。存储清理上限在 `/image` 图片管理的「存储空间」里改。

想用自己的域名：项目 →「自定义域」→「设置自定义域」，按提示操作。

## 五、免费计划够不够用

| 服务 | 免费额度 | 本站怎么用 |
| --- | --- | --- |
| Workers / Pages Functions | 每天 10 万次请求，每次最多 10 毫秒 CPU | 站点的每个请求都经过外壳，静态文件也算。打开一次页面约 20～30 次请求，再次打开时有缓存会少很多，个人或小群使用足够。超过当天额度会报错，第二天恢复。一键更新、上游更新已在免费计划上实测可用。 |
| R2 | 每月 10GB 存储、100 万次 A 类操作（写入）、1000 万次 B 类操作（读取） | 云同步数据、生成的图片、在线更新的上游页面都存在这里。用量在 `/image` 图片管理的「存储空间」里查看；超出清理上限（默认 9 GB）时，聊天页会每天最多提醒一次，可选择删除最早的图。 |
| Pages | 每月 500 次构建 | 一键更新每次产生一次部署；即使计入构建次数，也远远用不完。 |

额度以 Cloudflare 官方页面为准：[Workers 价格](https://developers.cloudflare.com/workers/platform/pricing/)、[R2 价格](https://developers.cloudflare.com/r2/pricing/)。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 改了绑定或变量没生效 | 重新部署一次（「一、5」）。 |
| 同步报 `Missing R2 binding` | 绑定名必须是 `RP_SYNC_R2`，改完重新部署。 |
| 一键更新提示「站点未设置同步密码」 | 设置 `RP_SYNC_PASSWORD` 并重新部署。 |
| 一键更新提示「未设置 CF_API_TOKEN」 | 按「二」设置令牌，或用「下载部署包」手动更新。 |
| 一键更新提示「令牌查不到账户」 | 填 `CF_ACCOUNT_ID`，或给令牌加「帐户设置 → 读取」。 |
| 一键更新提示「找不到网址对应的 Pages 项目」 | 令牌的帐户资源要包含站点所在帐户，权限是 Pages「编辑」。 |
| 一键更新后页面没变 | 等半分钟；还不行按 Ctrl+F5 强制刷新。 |
| 上传 ZIP 后网站打不开 | 确认上传的是分发站下载的部署包（解压后根目录直接是 `index.html` 和 `_worker.js`），不是源码包。 |
